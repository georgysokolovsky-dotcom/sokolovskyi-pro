# PRO Мужчин

Самостоятельный SEO-сайт для мужчин о кризисах в отношениях, измене, разводе, ревности и возвращении к устойчивой жизни.

## Локальный запуск

```bash
npm install
npm run dev
```

## Публикация

Публикация выполняется через GitHub Actions в GitHub Pages после отправки изменений в ветку `main`.

Приватные исходники, внутренние заметки и рабочие материалы в публичный репозиторий не входят.
