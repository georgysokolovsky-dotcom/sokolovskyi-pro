# PRO Мужчин

Авторский сайт для мужчин о кризисах отношений, измене, разводе и жизни после расставания. Действующая версия использует Astro.

## Локальный запуск и сборка

```bash
npm ci
npm run dev
npm run check:release
npm run preview
```

`dev`, `build` и `preview` запускают Astro. Команды с суффиксом `:astro` сохранены для совместимости. Старый React-прототип запускается отдельными командами `dev:legacy`, `build:legacy`, `preview:legacy`; его сборка не используется в CI.

## Статьи

Материалы находятся в `src/content/articles/*.md`. Новые материалы создаются непосредственно по схеме `src/content.config.ts`; `migrate:articles` нужен только для переноса старого `articleData.js`.

В публичные страницы, подборки и sitemap попадают только материалы со статусом `published`. Ссылки из `relatedArticles` на неопубликованные материалы скрываются при рендере. Прямые ссылки на черновики в публичном тексте блокируются проверкой публичной границы.

Для просмотра черновиков:

```bash
npm run dev:drafts
```

Адрес: `http://127.0.0.1:4322/__drafts/`. Это отдельный локальный сервер. Маршруты черновиков подключаются только для команды `dev` с `DRAFT_PREVIEW=1`. При `build`, даже с этой переменной, их нет в графе маршрутов. Они имеют `noindex, nofollow`, без Article JSON-LD и без запросов аналитики.

Порядок карточек определяется датой публикации, при её отсутствии датой изменения. Старый список задаёт только порядок при совпадении дат. Время чтения рассчитывается из основного текста со скоростью 180 слов в минуту. Используется существующая социальная обложка по `article_id`, иначе портрет автора. Оглавление берётся из авторского списка либо реальных заголовков; пустое оглавление скрывается. Шаблон добавляет одну финальную кнопку вебинара.

## Источник посещения и кнопки

Входящие `utm_source`, `utm_medium`, `utm_campaign`, `utm_content`, `utm_term` сохраняются без подмены SEO-значениями. Частичная разметка остаётся частичной. Без разметки используются известный поисковый источник, Telegram, общий внешний переход или `direct / none`. Произвольный адрес источника не передаётся. Источник сохраняется при переходах по внутренним ссылкам через разрешённые параметры URL, без отдельного хранилища атрибуции.

Допускаются только короткие технические метки из латинских букв, цифр и символов `._~-`, без длинных цифровых идентификаторов, email, телефонов и URL. Не помещайте имена и другие персональные данные в метки рекламных кампаний. Статья передаётся отдельно через `article_id`, страница через `page_id` и `page_type`, место кнопки через `placement`. Настольное и мобильное меню различаются. `/go/webinar/` повторно фильтрует параметры перед переходом на действующий внешний адрес.

## Аналитика

Astro использует существующий идентификатор из `src/data/analytics.js`. Google Analytics загружается только на рабочем домене после сохранённого согласия. До выбора, при отказе, в локальном превью и при недоступном хранилище аналитика выключена. Выбор хранится в `pro_muzhchin_analytics_consent` до 360 дней. «Настройки cookie» открывают повторный выбор; отзыв блокирует отправку и удаляет доступные `_ga` cookie.

Отправляются один `page_view` на загрузку документа и одно `webinar_click` на нажатие. Автоматический просмотр выключен через `send_page_view: false`. Произвольные query и hash не передаются в адресе аналитического события. Текущая навигация использует полные загрузки страниц. Если будет добавлен клиентский роутер Astro, управление просмотрами нужно адаптировать и отдельно проверить настройку Enhanced Measurement в GA4.

## Проверки и публикация

`npm run check:release` проверяет контент, регрессии, сборку, внутренние ссылки и изображения, маршруты, публичную границу, SEO и фактически отрендеренные статьи. GitHub Actions выполняет эти проверки до загрузки артефакта GitHub Pages. Публикация запускается существующим workflow для `main` или вручную; локальная подготовка её не запускает.

Серверная MEN-воронка в `server/` и `lab/men-funnel/` является отдельной системой. Сборка сайта не требует её запуска. Внутренние отчёты, снимки и рабочие документы хранятся вне репозитория и публичной сборки.
